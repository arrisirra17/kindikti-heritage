## 7. Сайтты жергілікті компьютерде іске қосу тәсілі

Сайт заманауи модульдік JavaScript (ES Modules) жүйесін пайдаланатындықтан, оны жергілікті HTTP-сервермен іске қосқан жөн:

### 1-тәсіл (Python арқылы):
1. `source_code/` папкасына өтіңіз:
   ```bash
   cd source_code
   ```
2. Серверді іске қосыңыз:
   ```bash
   python -m http.server 8000
   ```
3. Браузерден `http://localhost:8000` мекенжайын ашыңыз.

### 2-тәсіл (Node.js арқылы):
```bash
cd source_code
npx serve .
```

Толық нұсқаулық: `documentation/LOCAL_RUN_GUIDE.md` құжатында көрсетілген.
