# KİNDІКТІ Веб-қосымшасын жергілікті компьютерде іске қосу нұсқаулығы

Бұл нұсқаулықта **«KİNDİKTІ — Тастағы тарих»** веб-қосымшасын жергілікті компьютерде (Windows, macOS, Linux) интернетсіз немесе дербес ортада қалай іске қосуға болатыны қадам бойынша түсіндіріледі.

---

## 1. Негізгі талаптар

Сайт заманауи бірбеттік веб-қосымша (SPA/PWA) ретінде React фреймворкі мен ES-модульдер (ECMAScript Modules) негізінде құрастырылған. Модульдік JS файлдары мен WOFF2 қаріптері қауіпсіздік саясатына (CORS / Same-Origin) сәйкес жұмыс істеуі үшін сайтты жергілікті жергілікті HTTP-сервер арқылы ашу ұсынылады.

---

## 2. Іске қосудың қарапайым әдістері

### 1-әдіс: Python арқылы (Ең оңай әрі әмбебап)
Егер сіздің компьютеріңізде Python (3.x нұсқасы) орнатылған болса:

1. Терминалды немесе PowerShell-ді ашып, `source_code` папкасына өтіңіз:
   ```bash
   cd source_code
   ```
2. Кірістірілген жергілікті веб-серверді іске қосыңыз:
   ```bash
   python -m http.server 8000
   ```
3. Браузерді (Google Chrome, Edge, Firefox, Safari) ашып, мына мекенжайға өтіңіз:
   ```
   http://localhost:8000
   ```

---

### 2-әдіс: Node.js / npx арқылы
Егер Node.js орнатылған болса:

1. `source_code` папкасында тұрып пәрменді орындаңыз:
   ```bash
   npx serve .
   ```
   немесе
   ```bash
   npx http-server -p 8000
   ```
2. Браузерде пайда болған сілтемені (`http://localhost:3000` немесе `http://localhost:8000`) ашыңыз.

---

### 3-әдіс: Visual Studio Code «Live Server» кеңейтімі арқылы
1. VS Code бағдарламасында `source_code` папкасын ашыңыз.
2. Sol жақтағы кеңейтімдер (Extensions) бөлімінен **Live Server** (авторы: Ritwick Dey) плагинін орнатыңыз.
3. `index.html` файлын тінтуірдің оң жақ батырмасымен басып, **«Open with Live Server»** батырмасын таңдаңыз.
4. Веб-қосымша әдепкі браузерде автоматты түрде ашылады.

---

### 4-әдіс: Тікелей `index.html` файлын ашу
- Заманауи браузерлерде (әсіресе Google Chrome немесе Edge бағдарламасында жергілікті файлдар үшін белгілі бір қауіпсіздік шектеулеріне байланысты) `index.html` файлын екі рет шертіп ашуға болады. Дегенмен, PWA Service Worker және модульдік скрипттердің толыққанды жұмыс істеуі үшін жоғарыда көрсетілген 1 немесе 2-әдісті (локалды HTTP сервер) қолдану ұсынылады.

---

## 3. Негізгі бөлімдерді тексеру
Сайт іске қосылған соң келесі бөлімдердің жұмысын тексере аласыз:
- **Басты бет:** Жобаның кіріспесі, ғылыми зерттеудің түсіндірмесі, интерактивті навигация.
- **Мұрағат (Archive):** Жартас жазуы, таңбалар мен жер бедерінің санатталған карточкалары, іздеу жолағы.
- **Фото және видео (Gallery):** Түпнұсқа экспедициялық фотосуреттер мен видеолар галереясы, әр бейнені ойнату мүмкіндігі.
- **Мұра картасы (Map):** Ұлы Кіндікті және Кіші Кіндікті аумағының интерактивті векторлық картасы.
- **Танып үйрен (Learn):** 3 бөлімнен тұратын эпиграфика және зерттеу мәдениеті бойынша интерактивті сабақтар.
