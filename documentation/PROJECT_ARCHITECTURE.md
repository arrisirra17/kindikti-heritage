# KİNDİKTİ Жобасының Архитектурасы және Құрылымы

Бұл құжатта **«KİNDİKTİ — Тастағы тарих»** веб-қосымшасының бағдарламалық архитектурасы, компоненттік құрылымы, пайдаланушы тәжірибесі (UX/UI) және технологиялық ерекшеліктері сипатталады.

---

## 1. Жобаның тұжырымдамасы мен мақсаты

«KİNDİKTİ — Тастағы тарих» — Маңғыстау / Үстірт өңіріндегі Кіндікті тауы аумағында орналасқан тарихи-мәдени мұраны (жартас жазулары, таңбалар, петроглифтер, жер бедерінің ерекшеліктері) зерттеу, ғылыми құжаттау және көпшілікке таныстыру мақсатында әзірленген цифрлық білім беру және мұрағаттық платформа.

Платформаның негізгі ерекшелігі — **академиялық жауапкершілік пен ғылыми шынайылық**. Сайтта тарихи деректер мен болжамдар бір-бірінен қатаң ажыратылып, зерттеушілерге нысандарды шынайы, өзгеріссіз түрде зерттеуге мүмкіндік берілген.

---

## 2. Қолданылған технологиялар (Tech Stack)

| Бағыт | Қолданылған технология | Сипаттамасы |
|---|---|---|
| **Платформа** | HTML5, CSS3, JavaScript (ES6+ Modules) | Заманауи веб-стандарттар |
| **Фреймворк** | React 18+ & React DOM | Компоненттік интерфейс және динамикалық күйді басқару |
| **Иконкалар** | Lucide Icons | Векторлық жеңіл интерфейс белгішелері |
| **Типографика** | Manrope Font (WOFF2) | Заманауи, оқуға қолайлы геометриялық гротеск қаріпі |
| **Офлайн мүмкіндік** | PWA (Service Worker + Manifest) | Интернетсіз жұмыс істеу (Cache API) |
| **Анимация** | Canvas Confetti, CSS Transitions | Интерактивті кері байланыс және микро-анимациялар |

## 3. Негізгі модульдер мен компоненттер

Веб-қосымша 5 функционалдық бөлімнен тұрады:

### 1) Басты бет (Home)
- **Hero-бөлім:** Жартас текстурасы фонындағы тақырыптық баннер, жобаның мақсаты.
- **Зерттеу аумағы:** Кіндікті тауы, экспедиция туралы негізгі ғылыми түсіндірме.
- **Жылдам сілтемелер:** Негізгі мұрағаттық және білім беру бөлімдеріне бағыттау.

### 2) Мұрағат (Archive Explorer)
- Санаттар бойынша сүзу: «Барлық мұра», «Жартас жазуы», «Таңбалар», «Жер бедері».
- Жылдам мәтіндік іздеу: тақырып, сипаттама немесе орналасуы бойынша.
- Карточкалар құрылымы: нысанның суреті, мәртебесі («Сараптау қажет», «Нақтылау берілген», «Автордың байқауы»), толық ғылыми сипаттамасы, дереккөзі және тексеру жағдайы.

### 3) Фото және видео галереясы (Media Gallery)
- **Экспедицияның түпнұсқа фотосуреттері (Original Photos):** 6 жоғары ажыратымдылықты (960x1280) түпнұсқа фотосурет. Толық өлшемде көру және құрылғыға жүктеп алу мүмкіндігі бар.
- **Жобаның бейнематериалдары (Videos):** 8 далалық видеожазба, ойнату/тоқтату батырмалары, ұзақтық индикаторы, мазмұндық түсіндірмесі.
- Санаттар бойынша бөлу: Жартас жазуы, Таңбалар, Жер бедері, Зерттеу барысы.

### 4) Мұра картасы (Interactive Heritage Map)
- Ұлы Кіндікті және Кіші Кіндікті тауларының орналасу сызбасы.
- Интерактивті нүктелер (POI): Ұлы Кіндікті шығыс беткейі (жартас жазуы), тас баспалдақтар мен ойықтар, кеуектер.
- Нүктені таңдағанда тиісті мұрағат жазбасына жылдам өту байланысы.

### 5) Танып үйрен (Interactive Learning System)
- Үш қадамдық модуль:
  1. *Жазу мен тіл:* Араб графикасы мен шағатай тілінің арақатынасы, транслитерация негіздері.
  2. *Тас бетіндегі дерек:* Эпиграфика әліппесі, ескерткішті құжаттау ережелері.
  3. *Дерек пен болжам:* Ғылыми зерттеу мәдениеті, бақылау мен түсіндірмені ажырату.
- Оқырманның сабақты меңгеру прогресі жергілікті жадта (`localStorage`) сақталады.

---

## 4. Офлайн және PWA архитектурасы
- `manifest.webmanifest`: Мобильді құрылғылар мен дербес компьютерде толыққанды дербес қосымша (Standalone App) ретінде орнатуды қамтамасыз етеді.
- `sw.js` (Service Worker): Барлық статикалық файлдарды (HTML, CSS, JS, қаріптер, суреттер) браузер кэшіне жазып алады, соның арқасында сайт ғаламтор желісіне қосылмай-ақ автономды түрде жылдам ашылады.
